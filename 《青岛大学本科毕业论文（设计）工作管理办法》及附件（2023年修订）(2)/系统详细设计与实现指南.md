## 2. 第五章：系统实现 (Chapter 5: System Implementation)

### 2.1 开发环境与关键技术
- **后端**: Java 17, Spring Boot 3.x, Hibernate/JPA.
- **前端**: Vue 3 (Composition API), Vite, Ant Design Vue, WaveSurfer.js.
- **模型端**: Python 3.13, FastAPI, PyTorch, Transformers.
- **大模型**: Qwen2.5-Omni (专注于多模态理解与深度思考推理)。

### 2.2 关键代码实现与解析

#### (1) 前端：多模态请求封装
前端需要将录制的音频 Blob 文件和文本 Prompt 组合为 `FormData` 发送。

#### (2) 后端：多模态请求中转 (Bridge)
后端作为中转层，确保安全性并进行业务审计。

```java
// backend_java/.../service/ModelService.java
public Map<String, Object> callModel(String prompt, MultipartFile audioFile) {
    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.MULTIPART_FORM_DATA);

    MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
    body.add("prompt", prompt);

    if (audioFile != null) {
        // 将上传的音频包装为 ByteArrayResource 转发给 Python
        ByteArrayResource audioResource = new ByteArrayResource(audioFile.getBytes()) {
            @Override public String getFilename() { return audioFile.getOriginalFilename(); }
        };
        body.add("audio_file", audioResource);
    }

    HttpEntity<MultiValueMap<String, Object>> requestEntity = new HttpEntity<>(body, headers);
    // 调用 Python FastAPI 服务
    return restTemplate.postForEntity(pythonServerUrl, requestEntity, Map.class).getBody();
}
```
