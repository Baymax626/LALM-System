# LALM 前端 UI 升级与功能优化计划

## 1. 核心目标
提升用户交互体验，将系统从“工具型界面”转型为“对话型助手”，同时移除冗余的难度感知模块，使界面更加简洁聚焦。

## 2. 主要修改内容

### 2.1 移除难度感知模块 (Difficulty Perception)
- **动作**: 从 `Dashboard.vue` 中彻底移除 `DifficultyGauge` 组件的引用。
- **原因**: 该模块目前以仪表盘形式占据较大空间，且其核心数据（难度分值）可以通过更隐蔽、更符合对话流的方式（如在回复旁显示一个小标签）来展示，或者根据用户需求完全隐藏。

### 2.2 引入“对话式”语音交互弹窗
- **交互流程**:
  1. 在 `Dashboard.vue` 右下角添加一个显眼的**悬浮语音按钮 (Floating Action Button, FAB)** 或在主操作区提供“点击提问”入口。
  2. 点击后弹出 **Ant Design Vue Modal (对话框)**。
  3. 对话框内集成优化后的 `AudioInput` 功能：
     - **实时波形可视化**: 增强视觉反馈，确保录音状态一目了然。
     - **智能状态流转**: 录音开始 -> 波动显示 -> 暂停/继续 -> 完成并自动关闭弹窗触发推理。
- **UI 优化**: 对话框采用磨砂玻璃质感 (Glassmorphism)，背景微透，居中显示，突出“正在倾听”的氛围。

### 2.3 优化推理过程展示 (Reasoning Display)
- **布局调整**: 移除侧边栏 (`a-layout-sider`) 的设置项，或将其整合进顶部菜单或抽屉。
- **卡片式流式输出**: 推理过程（意图识别、知识检索等）应以时间轴或气泡流的形式动态展开。
- **反馈增强**: 在模型“思考中”时，使用更有质感的 Loading 动画（如脉冲圆圈或渐变进度条）。

### 2.4 音频功能稳定性保障
- **采样率与编码**: 确保 `AudioInput.vue` 输出的 WAV 格式与后端/模型服务完全兼容。
- **自动播放**: 优化推理完成后模型语音回复的自动触发逻辑，解决部分浏览器自动播放权限受限的问题（通过弹窗交互作为触发点）。

## 3. 技术栈保持
- **Vue 3 (Composition API)**
- **Ant Design Vue** (用于 Modal, Buttons, Icons)
- **WaveSurfer.js** (用于录音回放波形)

## 4. 实施步骤
1. **备份现有文件**: 确保开发安全。
2. **清理冗余**: 移除 `DifficultyGauge` 相关代码。
3. **改造 `Dashboard.vue`**: 实现 Modal 控制逻辑及布局重排。
4. **重构 `AudioInput.vue`**: 适配弹窗布局，增强视觉动效。
5. **端到端测试**: 验证 ASR 准确度、推理流转及音频播放。
